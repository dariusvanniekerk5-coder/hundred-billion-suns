# Two Hundred Billion Suns

An interactive pixel-art spiral galaxy in WebGL. 360,000 stars coloured by spectral class,
eight voyagers on slow orbits, drawn at low resolution and upscaled so every star is a crisp
pixel block. Drag to tumble, scroll or pinch to fly closer, press **P** to change the pixel size.

Every point is a star. None of them are real.
